Covers

GUESS THE ORIGINAL

The rule for every cover: keep the layout, palette and lettering of the original, redraw the art from scratch, and swap the title for a project’s name. No brand marks are copied; each one carries the ADK star instead.

Name that cover. Each original is face down. Pick the book you think it is: get it right and the card turns over.

Note 01 · Type

An alphabet of my own

A geometric capital alphabet with one even stroke throughout: a round O, a Q whose tail runs flat along the baseline, then 0–9 and the everyday symbols in the same hand. Every free stroke end and every top-left corner is cut at one pen angle, a small edge the whole set shares. Each letter is drawn as SVG geometry; a font file comes next.

Draft 3 · A–Z, 0–9, symbols
Note 02 · Type

Redrawn for a logo

Thickening the letters for a logo trimmed them flat at the top and bottom and left the gaps uneven. Redrawn, every stroke is the same real weight, round letters overshoot a touch, spacing follows each letter’s shape, and K’s arm runs into the stem in one solid join.

Note 03 · Logo

Four ways to sign ADK Studio

A wordmark, a stacked lockup, an east needle and a seal, all in the new letters. The favourite so far is C: the full stop becomes the compass needle, resting north and swinging east when you point at it.

Favourite so far: C, east needle
Note 04 · Colour

Stone, tried and set aside

A whole-site palette in warm stone with ink type and one seal-red accent, after a calm studio avatar. On screen it read too dull against the work, so the site stays white, but the swatches are worth keeping.
