Scatter

An intro effect: each letter starts in a random spot and drifts into the word. Press the button to scatter it again.

    What it is
    On load, every letter gets a random offset. Removing the offset lets a long CSS transition carry it home, so it never plays the same way twice.
    Built with
    Originally React with refs and CSS transitions; this page is the same technique in plain JavaScript.
    Timeline
    Hand-coded in React in February 2024, while learning it. Rebuilt for this page in 2026.
