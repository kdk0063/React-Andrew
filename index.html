§03 Practice
Method

Build the unhappy path first

Loading, empty, offline, expired session, half-filled form. Most of a real product is these states, so I build them before the demo path — the version that only works when everything goes right isn't finished.

Standard

Used, not demoed

The measure of internal software is whether someone reaches for it on a busy Tuesday. Fast pages, forgiving inputs, and no required field that exists only to satisfy the database.

Scope

Schema through typography

Owning both ends means the data model and the interface get to agree with each other instead of negotiating across a handoff — and the fix lands wherever the problem actually is.
